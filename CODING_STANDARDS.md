# Стандарты кода

Ревьюер сверяет с этим файлом каждый дифф; исполнитель читает его перед правкой
интерфейса. Нарушение правила — замечание ревью.

## Интерфейс

- Русский, коротко, без «!» и эмодзи. Числа с единицей через пробел: «60 кг × 10»,
  «90 с», время мм:сс. Все числа — tabular-nums.
- Цвета и шрифты только через tokens.css.
- Кнопки не меньше 44 px, настоящие `<button>`/`<a>`/`<input>`+`<label>`. Состояние не
  только цветом. Учитывать prefers-reduced-motion и safe-area-inset снизу.
- Целевой экран — Samsung A15, 384×832: окно `a15` в `.storybook/preview.tsx`, оно же
  окно по умолчанию. Мобильная история проверяет вёрстку в этом окне
  (`globals: { viewport: { value: 'a15', isRotated: false } }`), а не в рамке фиксированной ширины.

## SVG и графики

- В SVG с `preserveAspectRatio="none"` фигуры растягиваются вместе с ним. Линии рисуются
  с `vector-effect: non-scaling-stroke`. То, что должно сохранить форму (точки, маркеры),
  рисуется штрихом нулевой длины с `stroke-linecap: round` и non-scaling-stroke или
  HTML-элементом поверх SVG; `<circle>` и `<rect>` там становятся эллипсом и прямоугольником.
- Подписи (оси, даты, значения) не пересекаются: соседние видимые подписи стоят не ближе
  своей ширины по горизонтали и высоты строки по вертикали. Несовпадение текста или
  координаты пересечение не исключает: близкие разные позиции тоже налезают.
- Раскладку подписей и другую геометрию считает чистая функция, а тест перебирает размеры
  и данные. Пример: `web/src/ui/MultiLineChart/labels.test.ts`.
