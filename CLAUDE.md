Продукт: мобильный веб-трекер тренировок. В центре экрана тренировки — персонаж-чибик, который показывает упражнение, отдыхает и радуется финишу. Основной сценарий: телефон в зале или дома. Сайт может открываться внутри Telegram как обычная веб-страница. Аккаунты создаёт админ, саморегистрации нет. Роли: athlete (спортсмен), trainer, admin.

Стек (максимально просто):
- Один package.json, TypeScript везде.
- web/ — SPA на React + Vite. Без CSS-фреймворков и готовых тем: весь внешний вид — обычный CSS на переменных из tokens.css.
- UI-библиотека: Radix UI Primitives (пакеты @radix-ui/react-*, ставить по одному под задачу). Они безголовые: ни одного стиля, только поведение и доступность (фокус, клавиатура, aria). Нужны для панелей снизу (Dialog), переключателей и подобного. Простые элементы (кнопки, поля, карточки, полоска прогресса) делаем сами на <button>/<input>. Стилизовать через className и data-state атрибуты в CSS на токенах.
- server/ — Express: отдаёт /api/* и собранный SPA с одного порта. В разработке запускается через tsx watch.
- База: SQLite через better-sqlite3, чистый SQL, без ORM. WAL и foreign_keys включены.
- Видео — файлы в data/videos, в базе только путь. data/ в .gitignore.
- shared/types.ts — общие типы для сервера и SPA.
- Пароли: crypto.scrypt. Сессия: случайный токен в httpOnly-cookie + таблица sessions.
- Новую зависимость добавлять только с объяснением, зачем она нужна.

Домен:
- Тип упражнения: reps (повторы), weight (вес × повторы), time (мм:сс). Цель может быть диапазоном: «18–20 повт».
- Тренировка = блоки. Режимы блока: timed (разминка/заминка: упражнения по таймеру подряд), sets (все подходы упражнения, потом следующее), circuit (по кругу N кругов, отдых после каждого подхода).
- У блока можно пометить круги для видеозаписи (например, круг 2). В этих подходах чибик держит камеру, нажатие на неё запускает запись.
- Подход хранит план и факт. Тренер оставляет комментарии к упражнению или к видео; последний показывается под чибиком.

Экран тренировки: шапка (← шаг назад, название блока, ✕ выход), полоска прогресса из сегментов, облачко чибика (надстрочник + одна строка данных), чибик на светлом диске, слева кнопка «Техника», справа «Запись», под чибиком карточка с последним комментарием тренера (до 3 строк). Внизу: слева «Изменить»/«Пауза»/«+15 с», в центре ключевое действие («Готово», «Старт» или кольцо таймера), справа «Пропустить». Панели снизу: «Изменить», «Техника», «Комментарии тренера».

Правила интерфейса (дизайн-система Workout Tracker, исходники в design/):
- Интерфейс на русском, коротко, без восклицательных знаков и эмодзи. Числа с единицей через пробел: «60 кг × 10», «90 с», время мм:сс.
- Только светлая тема. Один акцент primary #0f766e. Fraunces — заголовки и большие цифры, Inter — всё остальное. Все числа — tabular-nums.
- Все кнопки не меньше 44 px. Настоящие <button>, <a>, <input>+<label>. Состояние никогда не передаётся только цветом.
- Учитывать prefers-reduced-motion и safe-area-inset снизу.

Работа: маленькие шаги, после каждого — npm run build без ошибок типов. Логику сценария тренировки держать чистыми функциями с тестами (vitest).
