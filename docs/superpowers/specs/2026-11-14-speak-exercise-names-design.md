# Голосовое название упражнения в разминке и заминке

Дата: 2026-11-14. Размер: небольшая правка, короткий дизайн.

## Зачем

Во время разминки или заминки пользователь может лежать и не смотреть на экран. Ему нужно знать
по голосу, какое упражнение следующее. Слышимый результат: «Следующее упражнение «Название»»,
затем привычные бипы.

## Цели

- Озвучивать название упражнения в разминке и заминке.
- Включать и выключать это в настройках профиля. Настройка хранится на сервере, как стиль и громкость звука.

## Не цели

- Озвучивать основную тренировку (подходы, отдых, таймерные упражнения).
- Записанные аудиофайлы, выбор голоса, скорости речи.
- Менять расписание бипов и длительность упражнений.

## Антицели

- Фраза заглушает бипы или сбивает отсчёт.
- Тишина без объяснений там, где голос недоступен, превращается в ошибку на экране: нет голоса значит просто нет озвучки.

## Подходы

1. Переключатель на сервере, голос через `speechSynthesis` (выбран).
2. Переключатель в localStorage: не переезжает между устройствами, остальные настройки так не работают.
3. Заранее записанные файлы: список упражнений открытый, записывать каждое невозможно.

## Решения

- Данные: колонка `users.speak_names` (INTEGER, 0/1, по умолчанию 0 — выключено), поле `speakNames: boolean`
  в `AuthUser`, запрос `apiSetSpeakNames` и маршрут в `authRouter`, по образцу `setSound`.
  Миграция по образцу `ALTER TABLE ... ADD COLUMN` в `server/db.ts`.
- Профиль: карточка с переключателем (Radix Switch или `SegmentedControl` «Вкл/Выкл» по образцу пола; на выбор
  исполнителя), текст по-русски без «!».
- Когда говорить (чистая функция рядом с `routineSignalAt`, с тестами):
  - первое упражнение набора: фраза в начале 5-секундного отсчёта;
  - остальные: за 6 с до смены, если шаг не короче 8 с, иначе фраза пропускается;
  - последнее упражнение набора: фразы нет.
- Озвучка: `speechSynthesis`, язык `ru-RU`. Громкость берётся из `soundVolume`; при 0 % голос молчит.
  Нет `speechSynthesis` или нет русского голоса: молча выключено, ошибок не показываем.
- Подключение: `WorkoutFlow.tsx`, рядом с вызовом `routineSignalAt`. Пауза таймера замораживает и фразы.
  Запуск речи только после жеста пользователя (как `beeper.unlock`).
- Настройка включена по умолчанию выключенной: поведение для существующих пользователей не меняется.

## Оставлено исполнителю

- Точная формулировка текста карточки и выбор компонента переключателя.
- Как отменять незаконченную фразу при паузе, пропуске шага и выходе из экрана.
- Сторис и тесты (`test:stories`, vitest) по правилам проекта.
