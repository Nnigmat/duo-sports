# Вкладка «Разминки»: передача фронтенду

Бэкенд готов (ветка `feat/routines-library`). Интерфейс делается по отдельному дизайну: экраны 1 и 2 из макета (список; карточка и правка). Термины: `GLOSSARY.md` — Разминка, Заминка, Ссылка на разминку. Решения и модель данных: `2026-11-11-routines-library-design.md`.

## Маршруты и навигация

- `web/src/app/routes.tsx`: `routines/*` рядом с `exercises/*`.
- `navItems.ts`: пункт «Разминки» в `sideNavItems` и `trainerSideNavItems` (как «Упражнения»); в нижней панели телефона места нет.
- Папка `web/src/features/routines/` по образцу `features/exercises/`: `RoutinesPage`, `RoutineListView`, `RoutineDetailView`, `RoutineForm`, `api.ts`, истории Storybook.
- Вложенные маршруты как у `ExercisesPage`: индекс (список), `new`, `:id` (карточка), `:id/edit`; id — slug; остальное ведёт на список.

## API (типы в `shared/types.ts`)

Читает любой вошедший, пишет тот, у кого `canAddExercises(role)` (trainer, admin); остальным 403 `{ error: 'Разминки меняют тренер и админ' }`.

| Запрос | Ответ |
|---|---|
| `GET /api/routines?kind=warmup\|cooldown` | `RoutinesResponse`: `{ routines: RoutineSummary[] }` (`id`, `kind`, `title`, `itemCount`, `totalSec`, `usedIn`); другой `kind` — 400 |
| `GET /api/routines/:id` | `RoutineDetail`: `Routine` + `usedIn` (все тренировки) + `usedBy` (только тренировки смотрящего: `workoutId`, `title`); 404 `{ error: 'Разминка не найдена' }` |
| `POST /api/routines` (`RoutineInput`) | 201 `Routine`; 400 — неверные поля, неизвестное упражнение, упражнение не `time`; 409 — такое название этого вида уже есть |
| `PUT /api/routines/:id` (`RoutineInput`) | `Routine`; состав заменяется целиком; slug не меняется; 404, 400, 409; 409 и при смене вида, пока разминка используется |
| `DELETE /api/routines/:id` | 204; 409 `{ error, workouts: [{ workoutId, title }] }` — разминка стоит в тренировках |

Пределы (`ROUTINE_LIMITS`): название 80 знаков, пояснение 300, упражнений до 30, секунды целые от 1 до 3600, `min` не больше `max`. Упражнения в `items` — slug из библиотеки (`GET /api/exercises`), только `kind: 'time'`; `sides` — две подписи, упражнение идёт два раза. `totalSec` — сумма `sec.max`, с удвоением при `sides`; считает сервер.

Удаление упражнения библиотеки, стоящего в разминке: `DELETE /api/exercises/:id` отвечает 409 «Упражнение стоит в разминке». Вкладке «Упражнения» нужно показать это сообщение.

## Экраны

1. Список: переключатель «Разминки (N) / Заминки (N)» (Radix ToggleGroup или Tabs, только поведение; N — из одного запроса без `kind`), поиск по названию на клиенте, карточка: название, «5 упр. · 4:30», «Используется в N тренировках», кнопка «Новая разминка» (только тренер и админ).
2. Карточка и правка: название, пояснение, упражнения по порядку (добавить из библиотеки только `time`, секунды, стороны, порядок), блок «Где используется» (`usedBy`, у ученика — его тренировки), сохранить, удалить. Удаление недоступно при `usedIn > 0`, кнопка объясняет почему; при 409 показать список `workouts`.
3. Для athlete экраны только на чтение, без кнопок записи.

Состояния: пусто (нет разминок этого вида), загрузка, ошибка запроса, 409 при дубле названия, 409 при удалении. Тексты русские, коротко, без «!» и эмодзи; «30 с», время мм:сс; числа tabular-nums. Кнопки не меньше 44 px; состояние не только цветом; prefers-reduced-motion; safe-area снизу; цвета и шрифты из `tokens.css`.

## Редактор тренировки

`GET /api/workouts/:id/plan` и ответ `PUT` отдают `Workout.routines?: { warmup?: { id, title }; cooldown?: { id, title } }` — подключённые разминка и заминка. Редактор показывает их неизменяемыми строками со ссылкой на `/routines/:id`.

- `Workout.blocks` в этих ответах уже собран: разминка первая, заминка последняя. Клиент может прислать блоки обратно как есть: сервер отбросит блок разминки или заминки, если у тренировки есть ссылка такого вида. Лучше слать только основные блоки (без `kind: 'warmup' | 'cooldown'` при наличии `routines`).
- Редактор YAML (`workoutYaml.ts`) блок `routine:` не принимает и говорит об этом: ссылки ставит импорт.
- Ссылки в экране тренировки и превью тренера ничего не требуют: `workoutOf` собирает всё на сервере.

## Импорт

`GET /api/import/context` теперь отдаёт ещё `routines: [{ id, kind, title }]` — разминки библиотеки для разбора `routine: slug`. Страница формата уже описывает `routines`; вывод списка доступных slug в справке — по желанию дизайна.

## Чего нет

Выбора разминки из интерфейса тренировки, автоматического чередования, нескольких разминок на тренировку (решения владельца).
