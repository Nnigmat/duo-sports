# Сохранённые ответы агента

Сюда кладут сырые ответы агента из ручного замера (спек «Формат тренировки v2», раздел «Замер»).
Тест `fixtures.test.ts` прогоняет каждый ответ через `buildWorkout` и проверяет, что черновик
открылся без пометок и без «Не разобрал» и ни одно упражнение запроса тренера не пропало.

## Как сохранить ответ

1. Сделайте сборку фикстуры (запрос тренера из спека) и возьмите сырой ответ агента: поле `workout`
   из ответа `POST /api/ai/workout-draft` (объект `AgentWorkout`, до ремонта).
2. Сохраните его как JSON-файл в этой папке. Только сам ответ: без токена, заголовков и данных
   пользователя.
3. Имя: `run-1.json`, `run-2.json` и так далее, до `run-4.json`.

## Библиотека

Ответ ссылается на id упражнений, поэтому рядом лежит `library.json` — массив `LibraryEntry`
с упражнениями, которые были в библиотеке на момент замера (выгрузка из `GET /api/library`, без
лишних полей не обойтись: нужны `id`, `name`, `aliases`, `kind`, `group`, `muscles`, `equipment`).
Один файл на все ответы. Наборы разминки и заминки берутся из `testkit.ts`. `library.json` сам
фикстурой не считается.

Пока в папке нет ни одного ответа, тест в прогоне показан как пропущенный.
